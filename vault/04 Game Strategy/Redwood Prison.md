# Redwood Prison — Long-Game Notes

> Design doctrine: economy, pacing, replayability, player fantasy. Verify each claim before trusting it.

## Open threads

- Prison management loop: build, staff, schedule, suppress, escape attempts.
- Replayability levers: random events, rival factions, varied prisoner traits.
- Player fantasy: warden-as-archmagos — order through discipline.

## Working principles

- Economy before content: a loop is only fun if the numbers breathe.
- Pacing via waves: calm build-up, crisis, recovery, escalation.
- Every feature answers: "does this create a story the player retells?"
